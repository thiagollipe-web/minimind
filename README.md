# MiniMind • MiniBuddies Educacionais

Companheiros virtuais de estudo para Android. A edição offline está em [`android-buddies`](android-buddies/README.md): doze aplicativos independentes com atividades, modo aprendiz, cuidados, som, mascote flutuante e memória local.

A aplicação Kotlin original, com integração ao Gemini, permanece em `app/`, com seus arquivos Gradle na raiz. A edição educacional tem seu próprio compilador em Python e não usa Gemini, LLM, chaves de API, Internet nem backpropagation.

Esta entrega é um **protótipo funcional compilado**, com catálogo inicial pequeno. Não representa um tutor completo nem comprova melhora educacional. Consulte os limites e a validação na documentação da edição offline.
